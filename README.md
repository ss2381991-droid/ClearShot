# ClearShot Camera

An installable camera app for Android and iPhone (a web app, not a Play Store or App Store app).

## Put it online with GitHub Pages (works from a phone)
1. On github.com create a new public repository, for example `ClearShot`.
2. Choose "Add file" then "Upload files". Upload every file in this folder to the top level (not the zip itself). Commit.
3. Open Settings, then Pages. Under "Build and deployment" choose "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. Wait for GitHub to show the site address, then open it on your phone.

## Install
- Android (Chrome): tap "Install ClearShot on this phone", or browser menu then "Install app".
- iPhone (Safari): tap Share, then "Add to Home Screen".

Allow camera access when asked.

## Update later
Upload the changed files over the old ones. Open the app while online; close and reopen it to get the new version.

## Notes
- The app opens offline after one successful online visit.
- AI person cut-out and face tracking download from the internet the first time you use them.
- Everything in a public repository can be seen by anyone. Do not upload personal photos or secrets.
